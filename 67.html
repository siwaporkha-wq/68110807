DEPLOYMENT & INTEGRATION GUIDE

คู่มือเชื่อมต่อ Google Sheet และอัปโหลดขึ้น GitHub + Vercel

ทำตามขั้นตอนด้านล่างเพื่อให้เว็บไซต์ทำงานสมบูรณ์ครบทุกเงื่อนไขของโจทย์

1

โครงสร้างไฟล์และโฟลเดอร์เก็บรูปแยกต่างหากบน GitHub

สร้าง Repository ใหม่บน GitHub และจัดวางไฟล์ให้มีโฟลเดอร์ images/ แยกเก็บรูปสินค้าแต่ละ SKU ดังนี้:

shampoo-landing-page/
├── index.html              # ไฟล์หลักของเว็บไซต์ (นำโค้ดหน้านี้ไปบันทึกชื่อ index.html)
└── images/                 # โฟลเดอร์เก็บรูปภาพสินค้าแยกต่างหากตามโจทย์
    ├── sku-01.png          # รูปภาพยาสระผมสูตรสมุนไพรลดผมร่วง (SKU-01)
    ├── sku-02.png          # รูปภาพยาสระผมสูตรอ่อนโยนบำรุงหนังศีรษะ (SKU-02)
    └── sku-03.png          # รูปภาพครีมนวดผมเข้มข้น (SKU-03)

หมายเหตุ: ในโค้ด HTML นี้ได้ตั้งค่าแท็ก <img src="images/sku-01.png"> ไว้เรียบร้อยแล้ว พร้อมระบบแสดงภาพกราฟิกสำรอง (Fallback SVG) อัตโนมัติหากยังไม่ได้อัปโหลดไฟล์รูปภาพจริง

2

โค้ด Google Apps Script สำหรับเชื่อมต่อ Google Sheet

  1. เปิด Google Sheets สร้างชีตใหม่ ตั้งชื่อแท็บด้านล่างว่า Orders
  2. ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  3. ลบโค้ดเดิมออก แล้ววางโค้ดด้านล่างนี้ลงไป จากนั้นกด บันทึก (Save)
  4. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > รายการใหม่ (New deployment) เลือกประเภทเป็น เว็บแอป (Web app) และตั้งค่าผู้มีสิทธิ์เข้าถึงเป็น ทุกคน (Anyone)
  5. คัดลอก Web App URL มาวางในช่องเชื่อมต่อที่หน้าสั่งซื้อสินค้า
3

นำขึ้นโดเมนของ Vercel

1. เข้าสู่เว็บไซต์ vercel.com และล็อกอินด้วยบัญชี GitHub
2. กดปุ่ม Add New... > Project แล้วเลือก Repository ที่เก็บไฟล์ index.html และโฟลเดอร์ images/
3. กดปุ่ม Deploy รอประมาณ 30 วินาที จะได้ลิงก์โดเมน https://your-project.vercel.app พร้อมส่งงานทันที!
